# Golgappa Junction 1 multi-page website

## Pages
- `index.html` — Home
- `menu.html` — menu with category filtering and search
- `about.html` — restaurant story
- `gallery.html` — food photo gallery
- `contact.html` — phone, address, map, owner placeholder and contact details
- `styles.css` — shared responsive styling
- `script.js` — mobile navigation and menu filtering

## Local preview
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder.
